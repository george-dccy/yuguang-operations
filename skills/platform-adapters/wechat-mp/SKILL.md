# WeChat Official Account Adapter

## Purpose

Create WeChat article drafts from approved Notion publish tasks.

## Input

- Cover image
- Content images
- Title
- Long-form body

## Rules

- Only process approved publish tasks.
- Keep human approval as final gate.
- Save draft only by default.

## Browser Flow

1. Open WeChat official account editor.
2. Create article draft.
3. Upload images.
4. Fill title and body.
5. Save draft.
6. Return result.
